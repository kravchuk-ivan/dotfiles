# dotfiles

Personal dotfiles across operating systems and devices: keyboard
remappings, terminal and editor configuration, Chromium browser
configuration and automations, shortcuts, and more.

Clone the repository to `~/dotfiles`; several scripts and aliases depend
on that exact path. Setup steps for individual components are documented
in comment blocks within the files themselves and/or in a README within
their own directory where one exists.

The commit convention and color-scheme rationale are defined in `CLAUDE.md`.
